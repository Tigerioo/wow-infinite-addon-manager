# 魔兽插件管理器

一个面向《魔兽世界》无限服的插件更新管理器项目。计划检查个人 GitHub 仓库的 Release，并将插件安装到用户指定的游戏目录。

## 当前状态

目前只有交互原型，尚未实现真实的 GitHub 连接、自动检测、下载或文件安装。原型中的仓库、插件和路径都是示例，不会读写游戏文件；演示状态刷新后不保留。

打开 [交互原型](preview/index.html)，即可体验插件列表、模拟检查和安装、添加插件、修改目录及查看更新记录。

## 计划的核心流程

1. 选择游戏插件目录，添加插件的 GitHub 仓库。
2. 确认 Release 附件与插件的安装路径和压缩包结构。
3. 定期检查版本；符合规则时下载并安装。
4. 查看更新记录，遇到无法匹配或安装失败时暂停并提示处理。

正式实现需要明确客户端版本、真实目录和 Release 包结构。安装过程应预检路径及附件、备份已有插件，并在失败时恢复；不得覆盖与插件无关的文件或游戏用户数据。
