# 魔兽插件管理器

macOS 本机工具，用于跟踪公开 GitHub 仓库的正式 Release，并将指定的插件 ZIP 安装到用户选择的《魔兽世界》无限服插件目录。

## 使用

1. 打开应用，选择客户端实际使用的 `AddOns` 文件夹。
2. 添加插件，填写公开 GitHub 仓库、Release ZIP 附件名（或 `MyAddon-*.zip` 这样的通配规则）和插件文件夹名。
3. 开启自动更新后，应用会检查并安装；应用运行期间每 6 小时检查一次，也可以手动检查。退出应用后不会后台运行。

更新前请退出游戏。ZIP 附件规则必须唯一匹配，插件文件夹名仅支持英文字母、数字、下划线和连字符。一个 ZIP 须恰好包含一个插件，插件根目录内须有对应的 `文件夹名.toc`。暂不支持私有仓库、预发布版本、ZIP64、加密或分卷 ZIP，以及一个压缩包安装多个插件。

## 目录和恢复

首次安装时，如果目标目录已有同名插件，自动更新会停止，不会自动覆盖。核对后可选择“接管已有插件”，经确认后应用将备份旧目录并安装指定 Release；插件目录中的本地修改不会自动合并。已安装并由本应用管理的插件更新时，应用会把旧目录保留为 `AddOns` 内以 `.addon-manager-backup-` 开头的隐藏备份目录。备份不会自动删除。配置只保存在本机的 `~/Library/Application Support/WoWAddonManager/settings.json`。

安装中断后如出现以 `.addon-manager-recovery-` 或 `.addon-manager-install-` 开头的目录，应用会停止继续安装并显示路径。请先关闭应用并核对插件目录与恢复目录，再手动恢复；不要删除尚未检查的备份。插件目录之外的文件不会被安装器操作。游戏设置与存档位置由客户端决定，请在使用前自行确认。

## 构建

需要 macOS 13 或更新版本、Swift 和 Xcode 命令行工具。项目依赖 ZIPFoundation，由 Swift Package Manager 解析。

```sh
Scripts/build-app.sh /绝对路径/魔兽插件管理器.app
```

构建脚本不会覆盖已有目标。生成的应用为本机临时签名构建，尚未经过 Apple 公证。
